# Public

Prosty przegląd użycia/celu.

## Description

Katalog `public/` zawiera statyczne pliki serwowane bezpośrednio przez Next.js.

- `/images/` – obrazy wykorzystywane w treściach.
- `/js/legacy/` i `/css/legacy/` – fragmenty kodu z szablonu Kevix (tymczasowo zachowane).
- `next.svg`, `vercel.svg` – domyślne grafiki Next.js (zostawione w kodzie jako placeholdery).

## Getting Started

### Dependencies

* Next.js (automatycznie obsługuje katalog public)

### Installing

* Pliki są serwowane automatycznie przez Next.js
* Nie ma potrzeby dodatkowej instalacji

### Executing program

* Pliki są dostępne pod ścieżką `/` aplikacji
* Na przykład: `/images/logo.png` jest dostępne jako `https://example.com/images/logo.png`

## Help

W przypadku problemów sprawdź czy pliki są prawidłowo nazwane i umieszczone w odpowiednich podkatalogach.
