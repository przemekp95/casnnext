# App

Prosty przegląd użycia/celu.

## Description

Katalog `app/` zawiera kod źródłowy aplikacji Next.js - głównej aplikacji webowej projektu CASN.

## Getting Started

### Dependencies

* Node.js
* Next.js
* React
* TypeScript

### Installing

* Uruchom `npm install` w głównym katalogu projektu
* Skopiuj `.env.example` do `.env.local` i skonfiguruj zmienne środowiskowe

### Executing program

* Uruchom serwer deweloperski
```
npm run dev
```
* Otwórz http://localhost:3000 w przeglądarce

## Help

W przypadku problemów sprawdź konsolę deweloperską i upewnij się, że wszystkie zmienne środowiskowe są poprawnie skonfigurowane.
