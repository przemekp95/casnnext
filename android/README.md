# Android

Prosty przegląd użycia/celu.

## Description

Katalog `android/` zawiera konfigurację i kod źródłowy aplikacji mobilnej Android zbudowanej przy użyciu Capacitor.

## Getting Started

### Dependencies

* Android Studio
* Node.js
* Capacitor CLI

### Installing

* Zainstaluj Android Studio i skonfiguruj środowisko Android
* Uruchom `npm install` w głównym katalogu projektu
* Synchronizuj projekt z Android Studio

### Executing program

* Otwórz projekt w Android Studio
* Zbuduj i uruchom aplikację na urządzeniu lub emulatorze
```
npx cap run android
```

## Help

W przypadku problemów sprawdź dokumentację Capacitor i upewnij się, że zmienne środowiskowe Android są poprawnie skonfigurowane.
