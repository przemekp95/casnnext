# Lib

Prosty przegląd użycia/celu.

## Description

Katalog `lib/` zawiera pomocnicze funkcje i konfiguracje używane w aplikacji, w tym konfigurację bazy danych.

## Getting Started

### Dependencies

* Node.js
* Biblioteki używane w aplikacji

### Installing

* Funkcje są automatycznie importowane przez aplikację
* Upewnij się, że wszystkie zależności są zainstalowane: `npm install`

### Executing program

* Funkcje są używane przez komponenty aplikacji
* Nie ma potrzeby bezpośredniego uruchamiania czegokolwiek z tego katalogu

## Help

W przypadku problemów sprawdź importy w plikach używających funkcji z tego katalogu.
