# Components

Prosty przegląd użycia/celu.

## Description

Katalog `components/` zawiera wielokrotnego użytku komponenty UI:

- **Header**, **Footer** – wspólne elementy layoutu.
- **CtaSection** – sekcja CTA powtarzana w layoutach.
- **ArticleLayout** – szablon dla pojedynczego artykułu.

Komponenty są importowane w `app/layout.tsx` i poszczególnych podstronach.

## Getting Started

### Dependencies

* React
* Next.js
* TypeScript

### Installing

* Komponenty są automatycznie importowane przez aplikację
* Upewnij się, że wszystkie zależności są zainstalowane: `npm install`

### Executing program

* Komponenty są używane przez layout i strony aplikacji
* Nie ma potrzeby bezpośredniego uruchamiania czegokolwiek z tego katalogu

## Help

W przypadku problemów sprawdź importy w plikach używających komponentów.
