# GHCR artifacts

`.github/workflows/docker.yml` builds and publishes two repository images:

- app: `ghcr.io/<owner>/<repo>:<tag>`;
- Nginx: `ghcr.io/<owner>/casn-nginx:<tag>`.

It does not build a CASN Directus image. Directus is the separately pinned
upstream image documented in [directus-cms.md](directus-cms.md).

## Publication behavior

The workflow runs on pushes to `main` and `dev`, matching `v*` tags, and pull
requests to those branches. Its `build-and-push` job waits for the application
test job and Directus smoke job.

- A pull request builds the app and Nginx images without pushing them.
- A push to `main` or a matching tag publishes the app and Nginx metadata tags
  generated by `docker/metadata-action` (branch/tag/semver as applicable).
- A push to `dev` publishes the `dev` branch tags.

Tags locate a candidate artifact; they are not deployment inputs. Before a
deployment, resolve the exact manifests and use only:

```text
APP_IMAGE=ghcr.io/<owner>/<repo>@sha256:<64-lowercase-hex>
NGINX_IMAGE=ghcr.io/<owner>/casn-nginx@sha256:<64-lowercase-hex>
APP_REVISION=<40-lowercase-hex-git-sha>
```

`scripts/deploy/write-artifact-env.sh` rejects mutable references, malformed
digests, malformed revisions, and a revision different from
`EXPECTED_APP_REVISION`. The deployment workflow also pulls the supplied
digests and compares each OCI `org.opencontainers.image.revision` label with
`APP_REVISION`.

## Deployment boundary

`docker-compose.final.yml` and `docker-compose.portainer.yml` consume
`APP_IMAGE`, `NGINX_IMAGE`, `APP_REVISION`, and required secrets from a
deployment-only `.env`; both fail rendering when any required value is absent.
The Compose files start the upstream Directus digest directly and do not pull a
mutable CMS image.

Do not use `:main`, `:dev`, `:latest`, or a release tag in Compose deployment
variables. Do not infer publication, deployment, runtime health, or editor
acceptance from a successful image build. The approved rehearsal and rollback
sequence is in [deployment-reconciliation.md](deployment-reconciliation.md).
