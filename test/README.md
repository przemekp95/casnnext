# Test

Prosty przegląd użycia/celu.

## Description

Katalog `test/` zawiera testy jednostkowe i integracyjne dla aplikacji, zapewniające jakość i niezawodność kodu.

## Getting Started

### Dependencies

* Node.js
* Jest
* Testing Library

### Installing

* Testy są uruchamiane jako część głównego procesu instalacji
* Upewnij się, że wszystkie zależności są zainstalowane: `npm install`

### Executing program

* Uruchom wszystkie testy
```
npm test
```
* Uruchom testy w trybie watch
```
npm run test:watch
```
* Uruchom testy z pokryciem kodu
```
npm run test:coverage
```

## Help

W przypadku problemów sprawdź konfigurację Jest w `jest.config.ts` i upewnij się, że wszystkie zależności są poprawnie zainstalowane.
